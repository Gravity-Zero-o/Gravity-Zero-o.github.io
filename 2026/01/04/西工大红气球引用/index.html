1. Image-Based Visual Servoing of Quadrotors to Arbitrary Flight Targets (RA-L 2023) 技术解读

一、核心问题与研究目标

该文解决的问题是：

如何仅用机载单目视觉，在不依赖目标三维位姿、不依赖GPS、不假设目标平面运动的情况下，让无人机稳定追踪一个在三维空间任意机动飞行的目标？

困难点在于：

  • 四旋翼是强耦合、欠驱动、非线性系统
  • UAV 的俯仰 / 偏航旋转会直接污染图像误差
  • IBVS 在 3D 自由运动目标下容易失稳（传统 IBVS 只能处理平面或静止目标）

二、方法总体思想

他们的解决思路是一个非常“控制派”的路线：

用一个 虚拟相机坐标系（Virtual Camera），把真实飞行器姿态的“旋转污染”从图像误差信号里数学上消掉，然后在这个虚拟图像平面上重新构造一个可稳定的 IBVS 控制系统。

一句话总结：

他们不是让无人机适应视觉噪声，而是重新定义“你看到的图像坐标系”，让控制问题变得可控。

三、系统流程（算法全链路）

四、核心技术模块

1️⃣ 虚拟相机（Virtual Camera）

他们引入一个新的相机坐标系 V：

  • X 轴始终与世界系水平对齐
  • 把 UAV 的 pitch、yaw 旋转数学消除
  • 目标在该虚拟相机下的投影满足：

[
p = \frac{\lambda}{v_x} [v_y, v_z]^T
]

得到一个完全解耦的视觉雅可比矩阵：

[
\dot{p} = J_v [v, \dot{\phi}]^T
]

➡ 直接把 IBVS 从“姿态污染空间”变成“线性稳定空间”。

2️⃣ 改进的图像误差定义

传统 IBVS：

[
e = p - p_d
]

他们用虚拟平面重构后：

[
e_i = p_v - p_d
]

👉 消除了 UAV 转动对误差的扰动项。

结果：误差收敛性从“经验好用”升级为“有 Lyapunov 稳定性证明”。

3️⃣ 解析 IBVS 控制律（非学习、纯控制）

直接构造速度控制律：

[
v{vy} = k_1 v_u, \quad v{vz} = k_2 v_n
]

配合推导得到 thrust 和姿态角速度闭式解。

整套系统是：

  • 无网络
  • 无学习
  • 全 Lyapunov 稳定
  • 连续控制律

这是它比“深度学习飞无人机”更硬核的地方。

4️⃣ 单目距离估计 + 自动刹车机制

他们用一个非常巧的单目测距：

[
d = \frac{N_e}{N} d_e
]

当目标像素宽度变大时，自动降低前向速度 → 防止冲过目标。

五、创新点总结

创新 含义
虚拟相机 IBVS 首次用于 3D 自由运动目标追踪
改进图像误差项 数学上消除姿态旋转污染
全动力学 IBVS 不再用小角度假设
单目距离制动 保证不会“冲过目标”

六、性能指标与实验结论

指标 提升
图像误差中位数 ↓ 22.37%
图像误差 IQR ↓ 35.10%
最终追踪距离误差 10.3 m（对比方法 20.83 m）
姿态稳定性 明显更稳
支持目标运动形式 直线 / 平面 / 螺旋 3D

2. An Autonomous Intercept Drone with Image-Based Visual Servoing

（基于 IBVS 的自主拦截无人机）

一、它解决了什么更狠的问题

目标不是“跟踪”，而是：

拦截（intercept） ——
目标在 3D 空域高速机动，你必须算出拦截几何，而不是跟着它转圈。

拦截的本质不是 tracking，是：

让你和目标在未来某一时刻占据同一空间点。

这是一类导弹制导问题，但作者用的是纯视觉闭环完成。

二、系统总体结构

三、核心思想（关键突破）

他们发现一个关键事实：

传统 IBVS = 跟踪制导
PN（比例导航） = 拦截制导

于是他们做了一件非常优雅的事情：

把 PN 制导律“视觉化”，让它直接在图像平面工作。

即构造：

[
\dot{e}_p = -\lambda e_p - N \dot{\sigma}
]

其中 σ 是图像平面的视线角（LOS），
N 是视觉比例导航增益。

这本质上是：

导弹比例导航在像素空间的 IBVS 版本。

四、制导律结构

最终得到视觉制导角速度：

[
\omega = -k_1 e - k_2 \dot{\sigma}
]

第一项：拉你指向目标
第二项：拉你预测拦截点

➡ 这是 tracking → intercept 的数学跃迁。

五、为什么这比纯 IBVS 强

方法 你飞到哪
传统 IBVS 飞到“目标现在的位置”
本文方法 飞到“目标将要去的位置”

因此：

  • 不会绕圈
  • 不会慢慢尾追
  • 是导弹式一次性收敛

六、单目也能算拦截几何

他们发现：

[
\dot{\sigma} = \frac{u \dot{v} - v \dot{u}}{u^2 + v^2}
]

完全只依赖像素运动。

这一步非常狠：

不用知道目标速度、不用深度、不用定位，直接用光流角速度完成 PN。

3. Interception of an Aerial Manoeuvring Target using Monocular Vision（Robotica 2022）

一、它真正解决的不是“跟踪”，而是“可捕获性”

它不是问：

目标在哪？

而是问：

在完全不知道深度、不知道目标速度、不做轨迹预测的情况下，
能不能保证你一定会撞上它？

这在制导理论里叫：

Capturability Guarantee（可捕获性保证）

这已经不是视觉伺服，这是导弹数学。

二、它的“极简主义”核心思想

他们提出一个极端克制的设计哲学：

不用深度
不用速度
不用预测
不用像素误差
只用一件东西：

目标像素相对于图像中心的“朝向方向”。

他们让无人机始终做一件事：

让“相机中心的速度方向”对准“目标像素方向”。

也就是说，你不是飞向目标的“位置”，
而是飞向目标在你图像里的“方向射线”。

三、算法本体（干到骨头）

图像给你一个像素 (xₜ, yₜ)
你构造一条单位射线：

[
\hat{T}_c = \frac{1}{\sqrt{x_t^2 + y_t^2 + f^2}}

]

然后你直接设定：

[
V_{camera} = V_I \cdot \hat{T}_c
]

意思是：

让你的相机中心，沿着“这条像素射线”飞。

再变换回机体坐标，直接送 PX4。

没有误差项、没有控制律、没有滤波器。

这是一个几何必收敛制导律。

四、为什么这一定会拦截？（论文的杀手锏）

他们不是靠仿真证明，而是用导弹动力学的：

相对速度空间拓扑分析

他们在 (Vθ, Vφ, Vr) 空间证明：

  • 只要你的速度 > 目标速度
  • 该制导律会让：
    • 横向相对速度 → 0
    • 视线旋转率 → 0
    • 径向相对速度 Vr < 0

最终强制进入：

[
V\theta = 0,; V\phi = 0,; V_r < 0
]

这在制导理论中等价于：

零脱靶距离拦截轨道。

也就是说：

这是一个“有数学保证的视觉导弹”。

五、这篇论文比 PN / IBVS 更狠的地方

方法 你在干什么
IBVS 追目标“现在的位置”
PN 追 LOS 角速度
本文 直接压缩成“像素射线追击”

你不是控制误差
你是在控制 相对速度的拓扑结构

六、实验性能

  • 单目
  • 不用深度
  • 不用预测
  • 户外真实拦截
  • 对 5 m/s 机动目标成功率极高
  • 最小脱靶距离 ≈ 1–2 cm
  • 可证明只要你比目标快，你一定抓到它

这篇论文告诉你：

直接跳过一整个“预测 + 状态估计层”。

这已经不是无人机视觉，是：

像素级导弹制导几何。

你现在手里的三篇论文，已经构成一个完整谱系：

论文 解决哪一层
虚拟相机 IBVS 稳定跟踪
IBVS + PN 预测拦截
本文 极简几何必收敛拦截

你已经站在一个非常少人走到的分支深处了。

下一步，你完全可以开始写：

雷达–视觉联合几何拦截制导律
那会是正统续作，而不是花活。

4. High-Speed Interception Multicopter Control by IBVS

一、这篇论文的研究层级已经不是“算法”，而是飞行极限控制

问题不是：

  • 能不能拦截

而是：

在 高速度 / 大迎角 / 强非线性 / 高角速度 / 强欠驱动 状态下，
IBVS 控制是否还保持“几何收敛性 + 动力学可执行性”。

也就是说：

把前面几篇论文的“视觉导弹几何”，压进真实飞控的空气动力学极限里。

二、系统结构已经是“导弹级飞控”

他们的飞控分成三层：

这一步是真正让 IBVS 变成“可飞的导弹制导律”。

三、核心突破：加速度级 IBVS

以前 IBVS 输出的是“速度”
这篇输出的是：

期望空间加速度向量 a*。

他们把像素误差映射成：

[
a^* = -k_1 e - k_2 \dot{e}
]

然后用完整刚体模型逆解：

  • 需要多大 thrust
  • 需要多大 pitch / yaw 转动
  • 是否会饱和
  • 是否还能保持几何收敛

这一步，是把 IBVS 从“慢悠悠视觉跟随”，升级成：

极限机动导弹级制导加速度律

四、他们解决了一个飞控界很少有人敢碰的问题

在极限拦截中：

  • 大 pitch
  • 大 yaw rate
  • thrust 饱和
  • IBVS 假设全部失效

他们构造了一个重构雅可比矩阵：

[
\dot{e} = J_a a
]

让 IBVS 在 thrust 饱和区仍保持收敛。

这在飞控界是非常难的。
